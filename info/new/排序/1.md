好的，针对你的需求，我将提供一个方案，包含配置修改和拦截器实现，以实现只打印 Spring Boot (2.7.18) + MyBatis + MySQL 环境下，使用 SLF4J 记录的存储过程调用（`CALL` 语句）及其参数，而忽略其他 SQL 语句。

**核心思路**

1.  **MyBatis 拦截器:**
    *   拦截 `StatementHandler` 的 `prepare` 方法。这是因为所有类型的 SQL 语句（包括 `CALL`）最终都会通过 `StatementHandler` 来准备执行。
    *   判断 SQL 类型是否为 `CALL`。
    *   如果是 `CALL`，则获取完整的带参数 SQL 语句，并使用 SLF4J 记录。
    *   如果不是 `CALL`，则不进行日志记录（直接放行）。

2.  **日志配置 (logback.xml 或 logback-spring.xml):**
    *   配置一个专门的 logger，用于记录存储过程调用。
    *   将该 logger 的级别设置为 `DEBUG` 或更低的级别 (例如 `TRACE`)，以确保拦截器中的日志能够输出。  **不要设置为 `INFO` 或更高级别, 拦截器里用的是 `debug` 打印的.**
    *   （可选）配置 appender，例如控制台或文件输出，以方便查看日志。

**详细步骤**

**1. MyBatis 拦截器实现 (ProcedureCallInterceptor.java)**

```java
package com.example.demo.interceptor;

import org.apache.ibatis.executor.statement.StatementHandler;
import org.apache.ibatis.mapping.BoundSql;
import org.apache.ibatis.mapping.CallableStatement;
import org.apache.ibatis.mapping.MappedStatement;
import org.apache.ibatis.mapping.ParameterMapping;
import org.apache.ibatis.plugin.*;
import org.apache.ibatis.reflection.MetaObject;
import org.apache.ibatis.session.Configuration;
import org.apache.ibatis.type.TypeHandlerRegistry;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.sql.Connection;
import java.util.List;
import java.util.Properties;

@Intercepts({
        @Signature(type = StatementHandler.class, method = "prepare", args = {Connection.class, Integer.class})
})
public class ProcedureCallInterceptor implements Interceptor {

    private static final Logger procedureLogger = LoggerFactory.getLogger("ProcedureCallLogger"); // 使用专门的 logger

    @Override
    public Object intercept(Invocation invocation) throws Throwable {
        StatementHandler statementHandler = (StatementHandler) invocation.getTarget();
        MetaObject metaObject = MetaObject.forObject(statementHandler,
                org.apache.ibatis.reflection.SystemMetaObject.DEFAULT_OBJECT_FACTORY,
                org.apache.ibatis.reflection.SystemMetaObject.DEFAULT_OBJECT_WRAPPER_FACTORY,
                new org.apache.ibatis.reflection.DefaultReflectorFactory());

        MappedStatement mappedStatement = (MappedStatement) metaObject.getValue("delegate.mappedStatement");

        // 检查是否为 CALL 语句
        if (mappedStatement.getSqlCommandType() == org.apache.ibatis.mapping.SqlCommandType.CALL) {
             BoundSql boundSql = statementHandler.getBoundSql();
            String sql = getCompleteSql(mappedStatement.getConfiguration(), boundSql);
            procedureLogger.debug("Executing stored procedure: {}", sql); // 使用 debug 级别
        }

        return invocation.proceed();
    }
    
    private String getCompleteSql(Configuration configuration, BoundSql boundSql) {
        Object parameterObject = boundSql.getParameterObject();
        List<ParameterMapping> parameterMappings = boundSql.getParameterMappings();
        String sql = boundSql.getSql().replaceAll("[\\s]+", " "); // Remove extra spaces

        if (parameterMappings == null || parameterMappings.isEmpty() || parameterObject == null) {
            return sql;
        }

        TypeHandlerRegistry typeHandlerRegistry = configuration.getTypeHandlerRegistry();
        if (typeHandlerRegistry.hasTypeHandler(parameterObject.getClass())) {
            sql = sql.replaceFirst("\\?", getParameterValue(parameterObject));
        } else {
            MetaObject metaObject = configuration.newMetaObject(parameterObject);
            for (ParameterMapping parameterMapping : parameterMappings) {
                String propertyName = parameterMapping.getProperty();
                if (metaObject.hasGetter(propertyName)) {
                    Object obj = metaObject.getValue(propertyName);
                    sql = sql.replaceFirst("\\?", getParameterValue(obj));
                } else if (boundSql.hasAdditionalParameter(propertyName)) {
                    Object obj = boundSql.getAdditionalParameter(propertyName);
                    sql = sql.replaceFirst("\\?", getParameterValue(obj));
                }
            }
        }
        return sql;
    }

    private String getParameterValue(Object obj) {
        String value = null;
        if (obj instanceof String) {
            value = "'" + obj.toString() + "'";
        } else if (obj instanceof java.util.Date) {
          //  DateFormat formatter = DateFormat.getDateTimeInstance(DateFormat.DEFAULT, DateFormat.DEFAULT, Locale.CHINA);
            value = "'" + new java.sql.Timestamp(((java.util.Date) obj).getTime()).toString() + "'";
        }
        else {
            if (obj != null) {
                value = obj.toString();
            } else {
                value = "null";
            }
        }
        // 对特殊字符进行转义，防止 SQL 注入
        return value.replace("'", "''");

    }



    @Override
    public Object plugin(Object target) {
        return Plugin.wrap(target, this);
    }

    @Override
    public void setProperties(Properties properties) {
        // 可以从配置文件中读取属性，这里留空
    }
}
```

**2.  注册 MyBatis 拦截器**

有两种方式注册拦截器：

**a)  使用 `@Configuration` 和 `@Bean` (推荐)**

   ```java
   package com.example.demo.config;

   import com.example.demo.interceptor.ProcedureCallInterceptor;
   import org.apache.ibatis.session.SqlSessionFactory;
   import org.mybatis.spring.SqlSessionFactoryBean;
   import org.springframework.context.annotation.Bean;
   import org.springframework.context.annotation.Configuration;
   import org.springframework.core.io.support.PathMatchingResourcePatternResolver;

   import javax.sql.DataSource;
   @Configuration
   public class MyBatisConfig {

       @Bean
       public SqlSessionFactory sqlSessionFactory(DataSource dataSource) throws Exception {
           SqlSessionFactoryBean factoryBean = new SqlSessionFactoryBean();
           factoryBean.setDataSource(dataSource);
            // 设置 MyBatis 配置文件路径（如果需要）
           // factoryBean.setConfigLocation(new PathMatchingResourcePatternResolver().getResource("classpath:mybatis-config.xml"));
            // 设置 Mapper XML 文件路径
           factoryBean.setMapperLocations(new PathMatchingResourcePatternResolver().getResources("classpath:mapper/*.xml"));

           // 添加拦截器
           factoryBean.setPlugins(new ProcedureCallInterceptor());

           return factoryBean.getObject();
       }
   }

   ```

**b)  在 `mybatis-config.xml` 中配置 (如果使用 XML 配置的话)**
```xml
  <plugins>
      <plugin interceptor="com.example.demo.interceptor.ProcedureCallInterceptor"/>
  </plugins>
```

**3.  日志配置 (logback.xml 或 logback-spring.xml)**

```xml
<configuration>

    <appender name="CONSOLE" class="ch.qos.logback.core.ConsoleAppender">
        <encoder>
            <pattern>%d{HH:mm:ss.SSS} [%thread] %-5level %logger{36} - %msg%n</pattern>
        </encoder>
    </appender>

    <appender name="FILE" class="ch.qos.logback.core.FileAppender">
        <file>logs/procedure.log</file>
        <encoder>
            <pattern>%d{HH:mm:ss.SSS} [%thread] %-5level %logger{36} - %msg%n</pattern>
        </encoder>
    </appender>


    <logger name="ProcedureCallLogger" level="DEBUG" additivity="false">
        <appender-ref ref="CONSOLE" />
        <appender-ref ref="FILE" /> </logger>

    <root level="INFO">
        <appender-ref ref="CONSOLE" />
        </root>

</configuration>
```

**要点解释**

*   **`@Intercepts` 注解:**  指定拦截 `StatementHandler` 的 `prepare` 方法。
*   **`procedureLogger`:**  使用一个专门的 logger 名称，以便在日志配置中进行区分。
*   **`getCompleteSql`:** 获取完整的带参数的 SQL 语句。 这里处理了常见的参数类型，包括字符串、日期和基本类型，并进行了参数值的转义以防止 SQL 注入。你可以根据需要添加更多类型处理。  对日期类型，这里处理成了 `java.sql.Timestamp`格式, 如果需要其他格式,请自行修改.
*   **日志配置 `level="DEBUG"`:**  确保 `procedureLogger.debug()` 能够输出。
*   **日志配置 `additivity="false"`:**  防止存储过程日志被传递到 root logger，避免重复输出。
*   **根 Logger 级别:** 设置为 `INFO` 或更高，这样 MyBatis 的其他 DEBUG 日志（例如普通 SQL 查询）就不会输出，只输出存储过程调用。

**测试**

1.  创建一个简单的存储过程（例如，接受一个参数并返回结果）。
2.  在 MyBatis 的 Mapper XML 文件中定义一个 `CALL` 语句来调用该存储过程。
3.  运行你的 Spring Boot 应用程序，并调用该存储过程。
4.  检查控制台输出或日志文件，你应该只看到存储过程的调用及其参数，而没有其他 SQL 语句。

这个方案的关键在于使用了 MyBatis 拦截器来精确地识别和记录存储过程调用，同时通过日志配置来过滤掉其他不相关的日志信息。  拦截器中的 `getCompleteSql` 方法非常重要, 它负责将参数值正确地拼接到 SQL 语句中。
