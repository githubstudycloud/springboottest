3. 关键代码实现:

```java
// EnterpriseCollectHandler.java
@Component("enterpriseCollectHandler")
@RequiredArgsConstructor
public class EnterpriseCollectHandler implements TaskHandler {
    
    private final EnterpriseCollectService collectService;
    
    @Override
    public void handle(TaskContext context) {
        // 获取分片信息
        Integer shardingId = context.getShardingId();
        Integer shardingTotal = context.getShardingTotal();
        
        // 分片数据采集
        List<String> codes = collectService.getShardingCodes(shardingId, shardingTotal);
        codes.forEach(code -> collectService.collect(code));
    }
}

// EnterpriseCollectService.java
@Service
@RequiredArgsConstructor
public class EnterpriseCollectService {

    private final EnterpriseCollector collector;
    
    public List<String> getShardingCodes(Integer shardingId, Integer total) {
        // 1. 获取所有待采集的企业代码
        List<String> allCodes = getAllEnterpriseCodes();
        
        // 2. 分片处理
        return allCodes.stream()
            .filter(code -> Math.abs(code.hashCode() % total) == shardingId)
            .collect(Collectors.toList());
    }
    
    public void collect(String code) {
        collector.collect(code);
    }
}
```

4. 配置文件:

```yaml
# application.yml
collect:
  task:
    enabled: true
    tasks:
      - taskId: "enterprise-collect"
        taskName: "企业数据采集"
        taskHandler: "enterpriseCollectHandler"
        cronExpression: "0 0 1 * * ?"
        sharding:
          enabled: true
          total: 4
          
  mq:
    rabbit:
      task:
        exchange: collect.task
        queue: collect.task.queue
        routing-key: collect.task
      result:
        exchange: collect.result
        queue: collect.result.queue
        routing-key: collect.result
```

5. 数据采集分片执行流程:

```plaintext
1. 任务提交
TaskManager.submitTask(taskDefinition)
  └── TaskProducer.sendShardingTask()  # 发送4个分片任务消息

2. 消息分发
RabbitMQ
  └── 4个节点的TaskConsumer监听队列

3. 任务执行
TaskConsumer.onMessage()
  ├── 判断是否为当前节点的分片
  └── TaskExecutor.execute()
       └── EnterpriseCollectHandler.handle()
            ├── 获取分片的企业代码列表
            └── 执行采集
```

举例说明:
- 总共有1000个企业代码需要采集
- 配置4个分片
- 系统处理:
    1. 根据代码的hashCode % 4的值分配到不同分片
    2. 每个分片大约处理250个企业
    3. 4个节点并行执行各自的分片任务
    4. 所有分片执行完成后任务结束

优点:
1. 配置驱动 - 通过配置文件控制任务执行
2. 自动分片 - 系统自动处理数据分片
3. 并行执行 - 多节点并行提高效率
4. 可靠性好 - 基于消息队列的可靠投递
