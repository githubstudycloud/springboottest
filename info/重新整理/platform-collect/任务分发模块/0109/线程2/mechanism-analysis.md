# 多级任务处理运行机制分析

## 1. 整体架构

### 1.1 核心组件
- BatchTaskExecutor: 核心执行器，管理线程和任务调度
- BatchTaskConfig: 配置中心，管理所有运行参数
- TaskMetrics: 监控指标收集器
- TaskContext: 任务上下文，存储任务状态和信息

### 1.2 分层设计
1. 大版本层 (Level 0)
   - 并发度: 2个大版本同时处理
   - 职责: 协调和管理小版本任务

2. 小版本层 (Level 1)
   - 并发度: 每个大版本下5个小版本并发
   - 职责: 管理分页数据采集任务

3. 分页层 (Level 2)
   - 并发度: 每个小版本下10个分页并发
   - 职责: 实际的数据采集和处理

## 2. 运行流程分析

### 2.1 初始化阶段
1. 配置初始化
   ```java
   BatchTaskConfig config = BatchTaskConfig.builder()
       .corePoolSize(4)
       .maxPoolSize(20)
       .useVirtualThread(true)
       ...
   ```
   - 设置线程池参数
   - 配置并发限制
   - 初始化监控系统
   - 设置重试策略

2. 执行器创建
   ```java
   BatchTaskExecutor executor = new BatchTaskExecutor(config)
   ```
   - 创建线程池
   - 初始化信号量
   - 启动监控系统

### 2.2 任务执行流程

1. 大版本处理
   ```mermaid
   graph TD
    A[接收版本列表] --> B[创建大版本任务]
    B --> C{获取父级信号量}
    C --> D[查询小版本]
    D --> E[创建小版本任务]
    E --> F[释放父级信号量]
   ```

2. 小版本处理
   ```mermaid
   graph TD
    A[接收小版本列表] --> B[获取子级信号量]
    B --> C[查询数据总数]
    C --> D[生成分页参数]
    D --> E[创建分页任务]
    E --> F[释放子级信号量]
   ```

3. 分页数据处理
   ```mermaid
   graph TD
    A[接收分页参数] --> B[获取分页信号量]
    B --> C[采集数据]
    C --> D[处理数据]
    D --> E[释放分页信号量]
   ```

### 2.3 并发控制机制

1. 分层信号量
   - parentSemaphore: 控制大版本并发
   - childSemaphore: 控制小版本并发
   - grandChildSemaphore: 控制分页并发
   - totalTasksSemaphore: 控制总任务数

2. 动态调整
   ```java
   executor.setMaxThreads(newLimit);  // 动态调整线程池大小
   ```

### 2.4 监控和度量

1. 实时指标
   - 总任务数
   - 运行中任务数
   - 完成任务数
   - 失败任务数
   - 重试任务数

2. 性能指标
   - 任务执行时间
   - 平均响应时间
   - 最大响应时间
   - 最小响应时间

3. 分层统计
   - 每层任务统计
   - 每层性能统计
