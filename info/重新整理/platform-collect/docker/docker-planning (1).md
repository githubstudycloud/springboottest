# Docker 镜像分类与端口规划

## 1. Web服务层
| 类别 | 推荐镜像 | 默认端口 | 建议端口 | 说明 |
|------|----------|----------|----------|------|
| 反向代理 | nginx | 80,443 | 8080,8443 | 主要用于反向代理和静态资源服务 |
| 负载均衡 | nginx-proxy-manager | 80,443,81 | 8080,8443,8081 | 提供可视化的nginx配置管理 |

## 2. 数据库层
| 类别 | 推荐镜像 | 默认端口 | 建议端口 | 说明 |
|------|----------|----------|----------|------|
| 关系型数据库 | mysql:8.0 | 3306 | 13306 | 主流版本，性能稳定 |
| 时序数据库 | clickhouse/clickhouse-server | 8123,9000 | 18123,19000 | 适合日志和监控数据 |
| 文档数据库 | mongo:7.0 | 27017 | 37017 | 新版本，功能完善 |
| 缓存数据库 | redis:latest | 6379 | 16379 | 内存缓存，建议持久化 |

## 3. 消息队列层
| 类别 | 推荐镜像 | 默认端口 | 建议端口 | 说明 |
|------|----------|----------|----------|------|
| 消息队列 | rabbitmq:3.12-management | 5672,15672 | 25672,35672 | 带管理界面版本 |
| 分布式消息 | bitnami/kafka | 9092 | 29092 | 高吞吐量消息队列 |
| 协调服务 | bitnami/zookeeper | 2181 | 32181 | Kafka依赖 |

## 5. 应用服务层
| 类别 | 推荐镜像 | 默认端口 | 建议端口 | 说明 |
|------|----------|----------|----------|------|
| Node应用 | node:18-slim | 自定义 | 3000-3999 | 轻量级node环境 |
| Python应用 | python:3.11-slim | 自定义 | 4000-4999 | 轻量级python环境 |
| Java应用 | eclipse-temurin:21 | 自定义 | 5000-5999 | JDK运行环境 |

## 端口分配规则
1. 外部访问端口：8000-9999
2. 内部服务端口：10000-19999
3. 数据库端口：30000-39999
4. 监控端口：40000-49999
5. 应用端口：3000-5999
6. 预留端口：20000-29999

## 部署建议
1. 使用 Docker Compose 管理服务编排
2. 创建独立的 Docker 网络隔离服务
3. 数据目录统一挂载到宿主机
4. 配置文件统一管理
5. 日志集中收集
6. 监控告警统一

## 安全建议
1. 生产环境禁止使用 latest 标签
2. 定期更新镜像版本
3. 限制容器资源使用
4. 使用非 root 用户运行容器
5. 配置文件敏感信息加密
6. 定期备份数据
