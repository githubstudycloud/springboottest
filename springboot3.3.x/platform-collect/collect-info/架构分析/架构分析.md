* MongoDB：数据存储
* Redis：缓存和分布式锁

5. 消息队列(MQ)

* TaskProducer：任务生产者
* TaskConsumer：任务消费者
* 支持消息重试和死信

二、数据处理流程
========

### 1\. 完整流程图

```
用户请求 -> API层接收 
    -> 创建任务实例(TaskInstance)
    -> 发送MQ消息(TaskMessage) 
        -> 消费者接收并处理
            -> 获取任务处理器(TaskHandler)
                -> 调用采集器(Collector)
                    -> 数据处理器(Processor)
                        -> 数据存储(Repository)
                            -> 返回结果(TaskResult)
```

1. 任务创建与分发

2. 任务执行

```java

    // 获取处理器执行任务

```

3. 数据采集与处理

```java
// 1. 采集器执行
CollectResult<T> collect(CollectContext context) {
    // 前置处理
    preProcess(context);
    
    // 执行采集
    T result = doCollect(context);
    
    // 后置处理
    postProcess(result);
}

// 2. 处理器处理
T process(T data, ProcessContext context) {
    // 数据处理链式调用
    return processors.stream()
            .reduce(data,
                (d, p) -> p.process(d, context),
                (d1, d2) -> d1);
}
```
